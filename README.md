# Polite Scraper - Books to Scrape

## Target Classification
- **Target Site:** Books to Scrape (https://books.toscrape.com)
- **Purpose:** Practice sandbox designed specifically for learning scraping.
- **Scope:** First 3 catalogue pages (~60 book pages total).
- **Data Collected:** Book title, product URL, raw price text, normalized numeric price (GBP), availability text, star rating, product description, source page URL, fetch timestamp.
- **Robots.txt Check:** `no robots file found` (404 response).

I will not reuse this code on another site without checking its rules and terms first.
